# 句纸 · 电纸书书摘壁纸

一个无需安装依赖的电纸书书摘壁纸编辑器。

## 使用

直接双击 `index.html`，或在当前目录启动任意静态服务器：

```powershell
python -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## 功能

- 输入书摘、作者和书名，实时生成壁纸
- 三种从参考风格归纳出的通用模板：蓝墨诗笺、黑墨留白、纸本手记
- 通过“品牌 → 型号”两级选择覆盖 Kindle、Kobo、文石 BOOX、掌阅 iReader、汉王等常见设备
- “通用”品牌下集中展示常用分辨率，并保留自定义尺寸
- 支持竖屏、横屏和 400–3000 px 自定义尺寸
- 输入框初始为空；预览与导出会用“把喜欢的句子，留在纸上。 / 作者 / 书名”作为轻量默认文案，输入后分别替换
- 可调整字号、行距、文字对齐和位置；画布下方可让出处框与书摘框按左边缘、中心线或右边缘对齐，并同步统一框内文字对齐方式
- 人工微调支持分别编辑书摘与出处；预览页额外支持选中“一起”同步拖动
- 页面不设独立 Header，品牌标识并入左侧窄栏；左侧只保留主文案与书摘、作者、书名输入
- 右侧画布上方常驻紧凑的版式与尺寸配置，不需要展开面板
- 画布下方先选择“书摘 / 出处 / 一起”，选中后才显示对应的人工微调菜单
- “一起”使用单一组合选框，组合移动时书摘与出处的相对位置保持固定
- 组合字号把手按组合框对角线成比例缩放两段文字，并保持原有字号比例
- 预览默认不选中任何对象；选择“书摘 / 出处 / 一起”后，再次点击同一项可取消选择
- 预览中拖动对象可移动位置，左右把手调整文本宽度，右下角把手直接调整字号
- 画布下方可一键恢复当前模板的默认版式，不会清空书摘内容
- 内容、模板、设备尺寸和全部微调会自动保存在本机，刷新页面后继续上次编辑
- “整体对齐 / 安全区显示 / 重置版式”常驻在编辑区域选择上方，先处理整体版面，再选择局部文字微调
- 内置旧式明朝、铅字宋体、仿宋书页、手写楷体四类字形气质，并可加载本地字体
- 可调整“油墨感”，模拟铅字印刷中轻微的墨色扩张
- 可直接拖动预览文字，键盘方向键也可微调
- 按设备原始分辨率导出 PNG
- 移动端使用“编辑 / 预览 / 导出”底部工作区；编辑页专注内容，预览画布下方承接完整微调面板，支持竖屏与横屏
- 响应式采用三段内容断点：宽屏双栏、平板工作区和手机纵向工作区，调整窗口宽度时配置、画布与微调菜单会分别重排
- 单栏编辑态的品牌、标题、说明和输入区使用连续缩放，书摘模块底部只保留一层导航安全间距

## 尺寸说明

设备型号会随代际更新，同一英寸也可能存在不同分辨率。选择前建议在设备的“关于”页面确认具体型号；列表不匹配时使用自定义尺寸。

当前尺寸档参考了 Amazon Kindle 支持页面、Rakuten Kobo 产品参数、BOOX 官方商店，以及掌阅与汉王的官方产品信息，整理日期为 2026-08-21。
